violeTM

AI threat modeling, self-hosted

violeTM is an AI security architect you can run yourself. Describe your system in plain English and it builds a data-flow model, walks every trust boundary, and produces a full STRIDE threat model — ranked findings, remediation, and mappings to OWASP ASVS and CWE. No SaaS account, no data leaving your machine: the only thing you bring is your own Anthropic API key.

Run it — one command

You need Docker and an Anthropic API key. Nothing else — no Node, no Bun, no Postgres to install. From a clone of the repo:

export ANTHROPIC_API_KEY=sk-ant-...
docker compose up

That brings up the app and its database together, applies migrations on boot, and serves violeTM at http://localhost:3000. It runs in local mode: no login, everything stays on your box. Stop it with Ctrl-C; bring it back with the same docker compose up.

Model a system

Create a project, describe the system — the components, how data flows, where the trust boundaries are — and violeTM extracts a structured model from your description.

Read the threat model

The report opens with a risk score, an input summary, and a rendered data-flow diagram, then lays out every finding: STRIDE category, the affected component, likelihood and impact, a plain-English "what this means for you", and concrete remediation with ASVS and CWE tags. You can export it, copy a fix prompt, or push findings to GitHub.

Run it without Docker

If you'd rather run from source, violeTM uses Bun and an embedded Postgres (pglite), so there's still nothing external to install:

export AUTH_PROVIDER=local
export DB_DRIVER=pglite
export PGLITE_PATH=./.threatlens/db

bun install
mkdir -p ./.threatlens/db
bun run db:migrate:local
bun run dev

Set ANTHROPIC_API_KEY in your environment to enable the AI features. Want to see a finished report without generating one? Seed the bundled sample (with the dev server stopped):

bun run scripts/seed-sample.ts

Where the data goes

Nowhere you don't control. In local mode violeTM stores everything in its own database on your machine and talks only to the Anthropic API, using the key you supply, to do the modeling. There's no violeTM account and no telemetry.
